The Strategy

Three Channels. One Metric.

Net new startups activated on the Claude API.

IRL Activation

Every event has one goal: developers who show up curious leave with a working Claude integration. Awareness is not the metric. Active API usage is.

Every touchpoint follows the same funnel: ecosystem event, API signup, first working build, GTM handoff, retention. That funnel gets documented, measured, and improved after every event.

  • —Claude Summer Series: four demo days at top NYC fund offices (a16z, Bessemer, Hugging Face, BoxGroup). Each event ends with working repos, not slide decks.
  • —Fall Build-athons at Columbia, NYU, and CUNY. Target: 80% of teams ship a working Claude integration by Sunday night.
  • —Monthly technical office hours. Open to any NYC startup building on Claude. Real debugging, real activation.
  • —NYC Claude Slack. Selective invite, high signal. Weekly drops of events, credits, and API updates.

Technical Content

Content written by someone who has shipped Claude in production. Not someone who read the docs.

  • —Series 1: Tool use and function calling. Two posts, two audiences. Beginner: your first Claude tool integration. Production: multi-tool agents in production, what we learned at Zumi. Both include working repos.
  • —Series 2: NYC Founders Building on Claude. Short, specific, technical spotlights on startups using the API. Pitched to Anthropic marketing for amplification.
  • —Live demos at every event. Working prototypes built for each audience. Code founders can fork and build on the same day.
  • —Regular syncs with Anthropic Product team to stay current on what is actually shipping.

Ecosystem Intelligence

Most evangelism is outbound. This channel is what makes the whole system compound.

  • —VC network activation. 1:1 calls and group dinners with partners at USV, a16z, Lerer Hippeau, Bessemer, and BoxGroup. Every intro has a clear handoff to Startups GTM.
  • —Weekly sync with Startups GTM. Every warm intro gets a clear next step. No leads fall through.
  • —Monthly ecosystem signal reports to product and GTM teams. What are NYC founders building? Where is Claude winning? Where is it losing?
  • —AI Atlas NYC is the infrastructure for this. A real-time map of the NYC AI startup ecosystem. The signal already exists. The job is surfacing it back to the right people inside Anthropic.
