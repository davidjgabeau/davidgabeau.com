Side Projects

Solo projects I work on in my spare time.

  • BrambleA macOS desktop app that runs in the background while you work in Claude Code or Codex, capturing the full event stream — prompts, tool calls, file edits, model responses — and turning it into a structured dev log. Built on Electron with a React/TypeScript renderer, a SQLite event store in the main process, and an Anthropic API pipeline that drafts a session summary the moment you stop recording. Everything is local-first: no sync, no server, no data leaving the machine unless you choose to ship something.
  • AI Atlas NYCA market map of New York's early-stage AI ecosystem, rebuilt nightly. An agent pipeline scrapes funding announcements, LinkedIn signals, and founder activity, re-clusters companies by category, and publishes a new version by morning. Built on a Node.js/TypeScript backend with a REST API I designed and host — integrated live below.
